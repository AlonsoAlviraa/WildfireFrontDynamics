Resumen Decisión Acciones Incendios Diccionario

Palabras difíciles explicadas en español llano

Este diccionario traduce los términos técnicos a un lenguaje claro para apoyar la toma de decisiones rápidas y seguras durante las emergencias forestales.

check_circle

GO

El sistema se atreve a proponer una orientación segura basada en los datos actuales. Las condiciones permiten avanzar.

Para el fuego: Indica que es seguro proceder con las tácticas planeadas en ese sector.
pause_circle

HOLD

Hay datos pero no bastan para dar una indicación segura. Espera / revisa la situación.

Requiere evaluación humana adicional antes de tomar una decisión.

cancel

ABSTAIN

El sistema se calla a propósito. La incertidumbre es demasiado alta o los datos son contradictorios.

No se asume ningún riesgo automatizado. La decisión recae completamente en el mando humano.

landscape

Frente

Línea del borde del fuego que avanza con mayor intensidad y velocidad.

Es la zona principal de propagación del incendio forestal.

satellite_alt

FIRMS NRT

Puntos calientes detectados por satélite en tiempo casi real.

Atención: (NO es el área quemada) Solo indica anomalías térmicas; puede tener desfase temporal o espacial.
smart_display

Decision Card

Tarjeta visual que resume la recomendación del sistema en un sector específico.

Muestra claramente el estado GO, HOLD o ABSTAIN con colores semáforo para una lectura inmediata.

Aviso: Los datos de satélite (FIRMS) pueden tener desfase. El perímetro oficial prevalece.
