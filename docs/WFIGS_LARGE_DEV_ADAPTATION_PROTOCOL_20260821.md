# WFIGS large-DEV fixed-source adaptation protocol — 2026-08-21

## Purpose

Run the preregistered corrected geometry + tile-standardized recipe on the
larger WFIGS TRAIN/DEV campaign from PR #152. This is a development experiment
only; it does not open or inspect confirmation or prospective manifests.

## Frozen recipe

- Source: the RCDA VAL-selected residual hybrid checkpoint with source seed 47.
- Adaptation seeds: 11, 29 and 47; probabilities averaged only after each
  member is selected on WFIGS DEV.
- Input: 16 RCDA channels, three signed front-geometry channels, and four
  valid-pixel median/IQR EO residual channels.
- Augmentation: vector-correct horizontal/vertical flips and rotations; the
  front-normal channels are transformed with the same orthogonal matrix as the
  wind channels.
- Trainable scope: decoder plus both residual input projections; the deeper
  encoder and context remain frozen.
- Optimizer: AdamW, learning rate `1e-4`, batch size 4, 18 epochs, patience 5,
  front-ring BCE weight `0.05`.
- Selection: event-macro growth IoU on the WFIGS validation split; no tuning on
  confirmation or prospective data.

The dataset is generated by
`scripts/run_wfigs_large_dev_campaign.py` with a maximum of 50 events per
GACC region (`events_per_region=50`; year only groups materialization).
The campaign is resumable and materializes only TRAIN and DEV. The final
report records the realized counts and rejection reasons.

## Guardrails and promotion gate

The adaptation runner must verify that the source was selected on RCDA VAL,
that TRAIN and DEV event IDs are disjoint, and that no WFIGS TEST manifest was
loaded. The frozen reference is the corrected three-seed expansion ensemble
(`event_macro_iou = 0.1361784859726811`). Promotion requires a pre-registered
improvement of at least `+0.005` on the same event-macro DEV metric. A result
below that gate is recorded as a development rejection and does not authorize
confirmation evaluation.

## Reproducibility command

```text
python scripts/run_wfigs_fixed_source_ensemble_dev.py \
  <rcda_seed47_checkpoint> \
  --wfigs-dev-root <large_campaign>/dataset \
  --rcda-normalization <rcda_train_normalization.json> \
  --output <large_adaptation_output>
```

Only the command, code, tests and sanitized aggregate metrics are suitable for
the public repository. WFIGS geometries, tensors, EO tiles, checkpoints and
per-pixel predictions remain private under the source rights terms.
