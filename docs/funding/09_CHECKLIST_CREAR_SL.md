# Checklist — crear SL en España (cuando toque)

**No es asesoramiento legal.** Confirma con gestoría/abogado. Úsalo cuando se cumplan las señales de la Fase 3 del playbook.

## Señales “ya”

- [ ] Call NEOTEC/EIC con deadline &lt; 90 días y quieres presentar  
- [ ] Partner pide NIF de entidad  
- [ ] Primer contrato de pago recurrente  
- [ ] Inversor pide vehículo  

## Pasos típicos

1. [ ] Elegir **denominación** (consulta Registro Mercantil Central — no coincidente)  
2. [ ] Definir **objeto social** amplio: software, I+D, consultoría tecnológica, tratamiento de datos geoespaciales, formación  
3. [ ] Aportar **capital** (mínimo legal vigente; preguntar gestor)  
4. [ ] **Estatutos** + notario + inscripción Registro Mercantil  
5. [ ] Obtener **NIF definitivo**  
6. [ ] Alta **AEAT** / obligaciones fiscales  
7. [ ] Alta **Seguridad Social** si hay autónomo societario / empleados  
8. [ ] **Cuenta bancaria** a nombre de la SL  
9. [ ] Domicilio social (puede ser coworking / virtual según normativa local)  
10. [ ] Registrar **organización en Funding & Tenders** (PIC)  
11. [ ] Actualizar one-pagers con razón social y CIF  

## Costes orientativos (orden de magnitud, 2026)
